自己开一个猫窝小镇

一台小服务器、一个域名，大约二十分钟。
开好以后，把猫猫搬过去，就能一直养下去。

猫窝的官网是体验服，不保证会一直开着。自己开一个小镇，数据就在你自己手里：你是这里的管理员，可以和朋友、家人一起住。

开服之前，准备三样东西

① 一台服务器

Linux 系统（推荐 Debian 12/13 或 Ubuntu 22.04/24.04），1 核 2G 起步，一个月几十块钱。买的时候记下它的公网 IP 和 root 密码。

选境外或香港机房最省事。国内机房的服务器，域名要先做 ICP 备案才能开网站。

② 一个域名

比如 cat.example.com（子域名就行）。在域名服务商的「DNS 解析」里加一条 A 记录：主机记录填 cat，记录值填服务器 IP。

网站的 HTTPS 证书会自动申请，所以一定要有域名。

③ 一台电脑

Mac 或 Windows 10/11 都行。用自带的「终端」（Mac）或「PowerShell」（Windows）登录服务器。

用 AI 帮忙的话，也是在这台电脑上装 AI 工具。

可选：一个 Anthropic API Key，猫猫说的话会更有灵气。不填也能完整地玩，之后在管理面板里随时能加。

方法一：跟着做

每一步复制一行命令，粘贴到终端里，回车。黑色框右上角有「复制」按钮。

  1. 登录服务器

    在电脑上打开终端（Mac：在启动台搜「终端」；Windows：在开始菜单搜「PowerShell」），输入下面这行，把 IP 换成你的服务器：

    ssh root@你的服务器IP

    第一次连接会问 yes/no，输入 yes 回车；然后输入 root 密码（输入时屏幕上什么都不显示，是正常的）。看到 root@…:~# 就登进去了，下面的命令都在这里输入。

  2. 安装 Docker 和 git

    apt-get update && apt-get install -y git curl && curl -fsSL https://get.docker.com | sh

    国内服务器把最后一段换成走阿里云镜像的版本：

    apt-get update && apt-get install -y git curl && curl -fsSL https://get.docker.com | sh -s -- --mirror Aliyun

    装好后确认一下，能看到 Docker Compose version v2.… 就对了：

    docker compose version
    安装脚本报错？（比如系统太新）

    Debian 13、Ubuntu 24.04 以上可以直接用系统自带的软件包：

    apt-get install -y git docker.io docker-cli docker-compose

  3. 下载猫窝

    git clone https://github.com/TTStick/meowtopia.git /opt/catnest && cd /opt/catnest
    服务器连不上 GitHub？

    在电脑浏览器里打开 GitHub 上的猫窝，点绿色的 Code → Download ZIP。然后在电脑的终端里（不是服务器里）进入下载目录，把它传上去：

    scp meowtopia-main.zip root@你的服务器IP:/opt/

    回到服务器的终端解压：

    cd /opt && apt-get install -y unzip && unzip -q meowtopia-main.zip && mv meowtopia-main catnest && cd catnest

  4. 一键部署

    把 cat.example.com 换成你的域名：

    ./deploy/setup.sh cat.example.com

    脚本会生成配置（包括一个随机的管理口令）、构建游戏并启动。第一次要等几分钟，看到「好了！」就成功了。

    国内服务器下载很慢？

    换成国内的 npm 源再运行：

    NPM_REGISTRY=https://registry.npmmirror.com ./deploy/setup.sh cat.example.com

    拉取 Docker 基础镜像也慢的话，可以在云厂商的控制台找「镜像加速」地址，按 部署手册第 6 节 配置。

    服务器只有 1G 内存？

    构建时内存可能不够，先加 2G 交换空间，再运行上面的部署命令：

    fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile && echo '/swapfile none swap sw 0 0' >> /etc/fstab

  5. 打开你的小镇

    • https://你的域名：官网首页（和这一页同一个样子）
    • https://你的域名/play/：游戏
    • https://你的域名/admin/：管理面板。口令用这行命令查：
    grep CAT_ADMIN_TOKEN /opt/catnest/.env

    刚部署完打不开？等一两分钟让证书申请好。还不行的话，检查域名解析是否已经指向服务器，以及云服务器的「安全组 / 防火墙」是否放行了 80 和 443 端口。

方法二：让 AI 帮你部署

不熟悉命令行也没关系。现在有能在电脑上「动手」的 AI 编程工具，比如 Anthropic 的 Claude Code：你用中文告诉它要做什么，它会自己读部署手册、登录服务器、一步步执行命令，每一步都会先问你同不同意。

  1. 装好 AI 工具

    以 Claude Code 为例。Mac 在「终端」里运行：

    curl -fsSL https://claude.ai/install.sh | bash

    Windows 在「PowerShell」里运行：

    irm https://claude.ai/install.ps1 | iex

    不想碰命令行，也可以装 Claude 桌面版，用里面的 Code。Claude Code 需要 Claude 的付费订阅（Pro 及以上）或 API 账号，并且要在 Anthropic 支持的地区使用；详细说明见官方文档。其他能在终端里执行命令的 AI 编程工具，也可以用同样的方法。

  2. 让电脑用「钥匙」登录服务器

    这样 AI 不需要知道你的服务器密码。在电脑的终端里生成一把钥匙（一路回车）：

    ssh-keygen -t ed25519

    把钥匙放到服务器上（只做一次，会让你输一次服务器密码）。Mac：

    ssh-copy-id root@你的服务器IP

    Windows（PowerShell）：

    type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@你的服务器IP "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"

    之后再输入 ssh root@你的服务器IP，不用密码就能直接登录了。

  3. 把要求告诉它

    在电脑上新建一个空文件夹，在里面启动 AI 工具（Claude Code：在终端里进入这个文件夹，输入 claude）。把下面这段话复制给它，改掉尖括号里的内容：

    请帮我把开源游戏「猫窝」部署到我自己的服务器上。

- 源代码：https://github.com/TTStick/meowtopia ，部署手册是仓库里的 DEPLOY.md。请先读它，按里面的方法用 Docker 部署（deploy/setup.sh）。
- 服务器：root@<服务器IP>，我已经能用 SSH 密钥登录。机房在 <国内 / 香港 / 海外>。
- 域名：<cat.example.com>，A 记录已经指向这台服务器。
- 每执行一条命令前，先用一句话告诉我它要做什么。
- 不要改 SSH、防火墙这类系统安全设置，需要的话先问我；不要在聊天里显示管理口令（CAT_ADMIN_TOKEN）。
- 部署好以后，确认 https://<域名>/healthz 返回 ok，再告诉我游戏和管理面板的地址，以及查管理口令的命令。

  4. 看着它做，点头就好

    它要执行命令时会先征求你的同意。看不懂的地方，直接问它「这一步是做什么的」。

两个小提醒

  • 别把服务器密码、API Key 发进聊天框；用上面的钥匙登录更安全。
  • 以后要更新版本、备份数据、看日志、排查打不开的问题，也可以直接交给它，比如：「帮我把服务器上的猫窝更新到最新版，更新前先备份数据」。

把猫猫搬到你的小镇

在体验服里养过猫？带上它一起走。

  1. 在原来的小镇打包

    打开游戏「设置 → 账号与安全 → 搬家去别的小镇」，点「打包」，保存「猫窝搬家包」这个文件。

  2. 在你的小镇申请搬进来

    打开 https://你的域名/play/，点「开始养猫」，在领养页最下面选「在别的猫窝小镇养过猫？搬家过来」，选这个文件，申请搬进来。

  3. 自己批准自己

    你就是这个小镇的管理员：打开 /admin/ →「搬家」，核对来源小镇的指纹（打包页面上也写着），点「同意搬来」。回到游戏，猫猫已经到家了。

会一起带走：猫猫本身（样子、性格、年龄、羁绊）、猫窝布置、背包和衣服、收藏、小鱼干、去过的地方和最近 200 篇日记。朋友、邻居和纸条会留在原来的小镇。

手机上怎么玩

  • 最简单：手机浏览器打开 https://你的域名/play/，点「添加到主屏幕」，就像一个 App，也能收到猫猫的小纸条。
  • 官网下载的 Android 安装包，连接的是官方体验服。想让 App 连你自己的小镇，要用源代码自己打包，见部署手册的「让各个 App 连到你的服务器」。

常见问题

要花多少钱？

服务器一个月几十元（或几美元），域名一年几十元。AI 生成猫语是可选的，按用量付费，管理面板里可以设每天的上限；不开也能完整地玩。

一定要有域名吗？

要。HTTPS 证书、通行密钥（面容 / 指纹登录）、通知都需要一个域名；只用 IP 的话浏览器会提示不安全，很多功能用不了。

国内服务器要注意什么？

域名要先完成 ICP 备案才能使用 80 / 443 端口。下载慢时换国内的 npm 源（见上面「一键部署」），GitHub 连不上就用 ZIP 上传。

怎么更新到新版本？

数据都在 Docker 卷里，更新不会丢：

cd /opt/catnest && git pull && ./deploy/setup.sh

用 ZIP 装的，下载新的 ZIP 解压覆盖到 /opt/catnest，再运行 ./deploy/setup.sh。

数据怎么备份？

服务器每天会自动备份数据库，保留最近 7 天。想拷一份出来：

cd /opt/catnest && docker compose cp app:/app/data/backups ./catnest-backups
打不开、报错了怎么办？

先看看游戏的日志：

cd /opt/catnest && docker compose logs --tail 100 app

也可以把报错复制给 AI 工具，让它帮你看。完整的说明在 GitHub 上的部署手册 DEPLOY.md。
