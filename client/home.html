这是一款不催你的养猫游戏。

你的猫有自己的性格和生活：白天趴在窗台上看云，傍晚在屋里跑酷，你不在的时候自己出门探险、交朋友、捡回小宝贝，天黑之前一定回家。你什么时候打开，它都在那里。

没有一张图片素材：猫、家具、小镇、居民都是代码实时“手绘”的线条画。下面的截图都来自真实运行的游戏。

在哪里都能陪着你

同一只猫、同一个账号。在一处摸摸它，另一处它也会记得。

网页版 · 浏览器里直接玩

网页

打开浏览器就能玩，什么都不用装。电脑上画面最大，小镇一眼能看得很远；手机浏览器里可以「添加到主屏幕」，像 App 一样全屏打开，也能收到它的小纸条。

马上玩

iPhone

白天它趴在窗台上看“云变成鱼的形状”，夜里蜷在小床上说梦话。

  • 登录凭证存在钥匙串里，删了重装也还在
  • 呼噜、发现宝贝时手里会轻轻一震
  • 自动把登录交给配对的 Apple Watch

Android

和 iPhone 版一样的游戏，按安卓的习惯打磨过。

  • 通知不依赖谷歌服务，国内手机也能收到
  • 返回键一层层退，不会一下子退出
  • 照片直接存进相册「猫窝」

Mac 菜单栏

你的猫常驻在屏幕右上角。它会眨眼、舔毛、打哈欠，晚上蜷成一团睡觉。点一下就是陪伴面板：摸摸、喂食、逗猫，也能直接打字对它说话。

Apple Watch

抬起手腕，它就在那里。轻点是摸摸，转动表冠是顺毛，顺够了会冒出小爱心。手表可以完全脱离手机使用。

它的小窝，跟着你的时间过日子

早上阳光从窗户斜斜照进来，下雨天窗上挂着雨丝，晚上落地灯和星星灯亮起来。它按时间、心情、性格和家里的家具决定做什么。

摸摸、顺毛、喂零食、拿羽毛逗它，或者直接对它说「去睡觉」「去河边看看」。每天它会有一个小心愿；晚上说一声「晚安」，它会踩踩奶，团成一团睡着。

窝外面，是一整个小镇

喷泉广场、面包房、咖啡馆、图书馆、邮局、花店、公园池塘、森林、小河与木桥、花田风车和灯塔。13 位猫猫居民按自己的作息过日子，所有玩家的猫都在同一个小镇里，会在路上碰鼻子、交朋友。

看它自己逛，或者「接管」亲自带着它走。小镇有实时的昼夜、雨雪和四季。

它会说话，也会给你写信

它说的话、猫和猫之间的对话、居民的闲聊和探险日记，都会结合它的性格、记忆、时间、天气和地点生成。你不在的时候，它的经历会变成信箱里的小纸条和一本日记。

不制造焦虑

  • 没有连续签到、好友数、点赞、排行榜、在线状态和已读回执。
  • 它不会饿坏：一周没人管也过得好好的，零食只是额外的小幸福。
  • 通知一天最多 4 条，有安静时段，从不说“你好久没来了”。
  • 不需要邮箱，也不需要手机号。起个称呼就能玩，换手机用找回码把猫领回来。
  • 「共养」可以和一位陌生人一起养一只小猫，你们之间只有一本交换日记。

网页版

马上开始

Android

直接下载安装，连接我们的服务器。Android 7.0 以上

下载 APK

安装时如果提示“未知来源”，在系统设置里允许浏览器安装应用就好。通知不需要谷歌服务。

iPhone

苹果不允许直接下载安装，用 Mac 上的 Xcode 从源代码装到自己的 iPhone：

  1. Mac 上装好 Xcode 和 Node.js 24，下载源代码
  2. 在项目里运行 npm install 和 npm run build:ios
  3. 用 Xcode 打开 ios/App/App.xcodeproj，在 Signing & Capabilities 里选你的 Apple ID
  4. 连上 iPhone，点 ▶ 运行

用免费 Apple ID？看这里

在 Build Settings 里把 CATNEST_BUNDLE_ID 改成独一无二的（比如 com.你的名字.catnest），再在 Signing & Capabilities 里删掉 Push Notifications。免费账号装的 App 7 天后要用 Xcode 再运行一次。详细步骤见 docs/apps.md。

Mac 菜单栏和 Apple Watch 版也在源代码里（macos/、ios/），用 Xcode 打开就能构建，默认连接我们的服务器。
